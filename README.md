# Jovi SmartFlow Camera

Landing page do projeto Jovi SmartFlow, uma câmera com IA de contexto que reconhece o que o estudante está apontando (texto, pessoa ou paisagem) e calibra ISO, luz e nitidez automaticamente.

O site apresenta a solução, o público-alvo, a galeria de telas do app, a equipe e um formulário de contato.

## Tecnologias utilizadas:

* Next.js 15 (App Router)
* React 19
* Tailwind CSS 4
* next/font (Inter, Space Grotesk e JetBrains Mono)
* next/image para otimização de imagens
* Vercel para o deploy

## Pré-requisitos:

* ode.js 18.18 ou superior (recomendado: versão LTS)
* npm (já vem com o Node.js)

Para conferir as versões instaladas:

node -v
npm -v

**No terminal**

## Como instalar as dependências:

Clone o repositório (ou extraia o .zip), entre na pasta do projeto e instale as dependências:

cd projeto-sp4
npm install

## Como executar o projeto

### Ambiente de desenvolvimento:

npm run dev

**No terminal**

Acesse http://localhost:3000 no navegador.

### Build de produção

npm run build
npm run start

**No terminal**

## Aonde foi utilizado IA:

__Foi utilizado a IA nesse projeto para tirar dúvidas como a utilização de Hooks, melhor forma de utilizar das informações do site (conteudo.js) e limpar o código para uma mais facil visualização.__
